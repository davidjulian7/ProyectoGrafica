ACTUALIZACION: MENU + 3 ZONAS DE INMERSION + CAMARA DE BUZO

Instalacion rapida (Git Bash):   bash ~/Downloads/instalar_todo.sh
(deja instalar_todo.sh y ProyectoGrafica_zonas.zip juntos en Descargas)

Manual:
1. En Git Bash, dentro de ProyectoGrafica:  git pull
2. Extrae este zip DENTRO de ProyectoGrafica y acepta reemplazar.
3. Abre src\ProyectoFinal\Proyecto\ProyectoFinal\ProyectoFinal.sln, Debug x64, F5.

Dentro de una zona: WASD nadar, Espacio/Ctrl subir/bajar, Shift aletear,
raton mirar, clic interactuar (en Naufragios recoge basura), F linterna, Esc menu.

Para agregar o mover animales: src/ProyectoFinal/include/zonas.h
Para reexportar modelos desde Blender 5.2: herramientas/exporta_zonas.py
