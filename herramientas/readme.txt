Scripts de apoyo (Python 3 + Pillow + numpy):
  pip install pillow numpy

genera_menu.py     -> tarjetas de zona, titulo, indicaciones e insignias HUD del menu
genera_cubemap.py  -> cubemap submarino de 6 caras

Nota: genera_menu.py usa la fuente Noto Sans CJK; en Windows cambia la variable FD
por la ruta de una fuente instalada (por ejemplo C:/Windows/Fonts/) y ajusta font().
